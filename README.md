## Important Documentation




## 🤔 AutoOS คืออะไร?

AtlasOS หรือ Atlas เป็นโครงการโอเพนซอร์สที่ช่วยปรับปรุง Windows ให้ดียิ่งขึ้น โดยเน้นการเพิ่มประสิทธิภาพด้านความเป็นส่วนตัว การใช้งาน และสมรรถนะของระบบอย่างสะดวกง่ายดาย ในขณะเดียวกันก็ยังคงรักษาฟังก์ชันการทำงานหลักและความสามารถในการ [ปรับแต่งตามความต้องการ] เอาไว้

## 👀 ทำไมต้อง Auto ?
### 🔒 ความเป็นส่วนตัวที่ดียิ่งขึ้น
Atlas จะลบระบบ Telemetry (การเก็บข้อมูลการใช้งาน) ส่วนใหญ่ออกจาก Windows และใช้ Group Policy จำนวนมากเพื่อลดการเก็บรวบรวมข้อมูลให้น้อยที่สุด อย่างไรก็ตาม AutoOS ไม่สามารถรับประกันความเป็นส่วนตัวนอกขอบเขตของ Windows ได้ เช่น ข้อมูลที่เกิดขึ้นบนเว็บเบราว์เซอร์หรือแอปพลิเคชันจากผู้พัฒนาภายนอก (Third-party)

### 📈 ประสิทธิภาพที่ได้รับการปรับปรุง
Atlas สร้างสมดุลระหว่างประสิทธิภาพและความเข้ากันได้ของระบบ โดยมีการปรับเปลี่ยนที่สำคัญหลายจุดเพื่อเพิ่มความเร็วและการตอบสนองของ Windows โดยไม่ทำให้ฟีเจอร์หลักเสียหาย AutoOS จะไม่ทำการปรับแต่งเพียงเพื่อให้รู้สึกไปเองหรือเพื่อผลลัพธ์ที่เห็นผลเพียงเล็กน้อย ซึ่งทำให้ระบบมีความเสถียรและรองรับการใช้งานได้กว้างขวางกว่า

### 🛡️ ฟีเจอร์ด้านความปลอดภัย
การปรับแต่ง Windows ส่วนใหญ่มักตัดฟีเจอร์ความปลอดภัยที่สำคัญซึ่งผู้ใช้จำเป็นต้องมีเพื่อรักษาความปลอดภัยของระบบทิ้งไป แต่ AutoOS เปิดโอกาสให้ผู้ใช้ปรับแต่งระดับความปลอดภัยได้เองตามความเสี่ยงที่ยอมรับได้ พร้อมทั้งให้ข้อมูลของแต่ละตัวเลือกแก่ผู้ใช้อีกด้วย ฟีเจอร์ความปลอดภัยทางเลือกบางส่วนได้แก่:

- Windows Defender และ SmartScreen
- Windows Update
- สามารถเปิด/ปิดการอัปเดตอัตโนมัติได้
- มาตรการป้องกันช่องโหว่ระดับ CPU (CPU mitigations)
- User Account Control (UAC)
- ฟีเจอร์ Core isolation

### ✅ ใช้งานง่ายยิ่งขึ้น
Atlas มีการปรับแต่งและตั้งค่าเริ่มต้นหลายอย่างเพื่อให้ Windows ใช้งานได้ง่ายขึ้น ซึ่งรวมถึงการลบแอปพลิเคชันที่ไม่จำเป็นออก (แต่สามารถติดตั้งกลับคืนได้) การปรับแต่งส่วนติดต่อผู้ใช้ (Interface) ในด้านต่างๆ การปิดโฆษณา และอื่นๆ อีกมากมาย

### 🔍 โอเพนซอร์สและโปร่งใส

ต่างจากไฟล์ ISO ของ Windows ที่ผ่านการดัดแปลงทั่วไป Atlas สามารถตรวจสอบการทำงานได้ง่ายกว่าเนื่องจากใช้ [AME Wizard](https://amelabs.net) โดย AME Wizard จะทำงานผ่าน Playbooks ซึ่งเป็นระบบที่มีลักษณะคล้ายสคริปต์และสามารถปรับแต่งได้ตามต้องการเพื่อดำเนินการงานต่างๆ
